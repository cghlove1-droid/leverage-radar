① 고점 대비 낙폭(MDD) 비교

각 거래일의 누적 최고 종가 대비 낙폭을 표시합니다. 조정종가 기준으로 분할을 반영한 데이터가 필요합니다.

기간 선택 시 누적 최고점은 전체 제공 데이터의 최초 시점부터 계산합니다. 선택 기간 안의 최대 낙폭은 별도 표기됩니다.

② 시장 위험지표

지표별 관측 시점이 다를 수 있습니다. RSI·200일선은 QQQ 일별 종가 기반이며, VIX·신용스프레드는 별도 데이터입니다.

④ 레버리지 투자 계산기

매수 회차별 가격과 투자금액을 입력하면 평균단가와 본전 회복률을 계산합니다. 브라우저 내에서만 계산하며 서버로 전송하지 않습니다.

모든 금액은 USD 기준. 소수점 수량을 허용합니다. 수수료, 환율 변동, 세금 및 분배금은 제외합니다.

⑤ 데이터 상태 · 가져오기

데이터최근 값기준일상태

CSV 형식: date,QQQ,TQQQ,SOXL (예: 2026-11-09,600.1,80.5,45.2). 가격은 분할 조정된 종가를 사용하세요.

사이트 자동 갱신은 저장소의 data/market.json을 매일 업데이트하는 방식입니다. 승인된 데이터 API를 연결해야 실제 값이 표시됩니다.

교육·정보 제공용. 투자 조언이 아닙니다. 3배 레버리지 ETF는 일간 수익률을 추종하며 장기 수익률이 기초지수의 단순 3배가 아닙니다. 데이터 이용약관과 공개 재배포 권한을 확인하세요.
